# Cpp

C++ 학습 예제 모음. 폴더 번호는 학습 단원 번호입니다.

| 폴더 | 주제 | 내용 |
|------|------|------|
| `02/` | 기본 입출력과 문자열 | cout/cin, 네임스페이스, `cin` 실패 처리, C 문자열과 `string`, `getline`, 헤더 파일 분리 |
| `03/` | 클래스와 객체 | 캡슐화(private/public), 생성자 오버로딩·위임 생성자, 소멸자 순서, inline 함수, struct와 class 차이, 파일 분리(`Circle`), 미니 프로젝트(`Calculator`, `Mini_Wallet`) |
| `04/` | 동적 메모리와 string | `new`/`delete`, 동적 배열·객체, `string` 비교·회전·파싱 |
| `05/` | 참조와 복사 | call by value/reference, 참조 반환, 복사 생성자, 얕은 복사 vs 깊은 복사 |
| `06/` | 중복 함수와 static | 함수 오버로딩, 디폴트 매개변수, 모호성, static 멤버·유틸리티 |
| `07/` | friend와 연산자 | friend 함수/클래스, 연산자 중복, 증감 연산자 |
| `08/` | 상속 | 업캐스팅·다운캐스팅, protected, 생성자/소멸자 호출 순서, 상속 모드, 다중 상속, 가상 상속(다이아몬드) |
| `09/` | 가상 함수와 다형성 | 오버라이딩, 동적 바인딩, 가상 소멸자, 순수 가상 함수와 추상 클래스 |
| `10/` | 템플릿과 STL | 함수/클래스 템플릿, `vector`, `map`, 반복자, `sort` |

## 참고

- 빌드 예: `g++ 03/01_basic_class_object.cpp -o run`
  (여러 파일 프로젝트는 폴더 안의 `.cpp`를 모두 컴파일: `g++ 03/10_file_splict_circle/*.cpp -o run`)
- 실행 파일(`*.exe`)은 `.gitignore`로 제외했습니다.
- `test.cpp`는 연습용 임시 파일이며 `myswap(c, d)` 뒤에 세미콜론이 빠져 있어 그대로는 컴파일되지 않습니다.
